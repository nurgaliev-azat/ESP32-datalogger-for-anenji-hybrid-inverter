# ESP32 Datalogger for Anenji Hybrid Inverter

Даталоггер для гибридного инвертора **Anenji 4.2 kW** на базе **ESP32**.

Проект предназначен для наблюдения за работой инвертора через встроенный веб-интерфейс без изменения его рабочих параметров и алгоритмов управления.

## Основные возможности

- Подключение ESP32 к локальной Wi-Fi-сети.
- Обмен данными с инвертором по Modbus TCP.
- Автоматическая передача инвертору IP-адреса и TCP-порта даталоггера по UDP.
- Мониторинг мощности сети, PV-массивов и нагрузки.
- Отображение мощности заряда и разряда батареи.
- Отображение напряжения сети, PV, нагрузки и батареи.
- Отображение режима работы инвертора.
- Отображение процента заряда батареи.
- Чтение и расшифровка кодов аварий и предупреждений.
- Встроенная адаптивная веб-панель ESP32.
- Анимированная схема потоков энергии между сетью, PV, батареей, нагрузкой и инвертором.
- График мгновенной мощности за текущий день.
- Почасовой учёт накопленной энергии.
- История накопленной энергии с представлением по часам, дням, месяцам и годам.
- Сохранение почасовой истории во встроенной EEPROM ESP32.
- Синхронизация времени через NTP.
- Поддержка настраиваемого часового пояса.
- Настройка Wi-Fi, IP-адреса инвертора и интервалов опроса через веб-интерфейс.
- Резервная точка доступа `Anenji-setup` при отсутствии подключения к сохранённой Wi-Fi-сети.
- Двуязычный интерфейс: English / Русский.
- Хранение настроек во flash-памяти ESP32 с использованием `Preferences`.

## Структура проекта

- `ANENJI_Dataloger.ino` — основная логика подключения, опроса Modbus TCP, обработки показаний и сохранения истории.
- `Registers.h` — описание регистров Anenji, единиц измерения, режимов работы, аварий и предупреждений.
- `web_server.h` — встроенный HTTP-сервер, веб-интерфейс, графики, API и страница настроек.

## Необходимые компоненты

- ESP32.
- Гибридный инвертор Anenji 4.2 kW.
- Wi-Fi-сеть.
- Arduino IDE или PlatformIO.
- ESP32 Arduino Core.

## Первоначальная настройка

1. Загрузите прошивку в ESP32.
2. Подключитесь к точке доступа `Anenji-setup` с паролем `12345678`, если ESP32 ещё не настроена или не может подключиться к сохранённой сети.
3. Откройте адрес точки доступа ESP32 в браузере.
4. Укажите имя и пароль Wi-Fi, IP-адрес инвертора, интервалы обновления и часовой пояс.
5. Сохраните параметры и дождитесь перезагрузки ESP32.
6. После подключения к рабочей сети откройте IP-адрес ESP32 в браузере.
7. Убедитесь, что инвертор доступен по указанному IP-адресу.

## Хранение данных

Настройки сохраняются во flash-памяти ESP32 через `Preferences`. Почасовые энергетические данные сохраняются в EEPROM в кольцевом буфере. При заполнении памяти новые записи замещают самые старые.

## Примечание

Проект предназначен для мониторинга параметров инвертора. Перед использованием проверьте IP-адрес инвертора, сетевые настройки и совместимость прошивки с вашей моделью Anenji.
